# GTP-Intersections
This is a companion code for the paper "5d SCFTs and Intersection Theory for Generalized Toric Threefolds" by Arguz, Bourget, Bousseau, Grimminger, Schafer-Nameki, 2026. 

To run it, download the two files 
  GTP_Intersection_Numbers.nb
  GTPIntersections.wl
in the same folder. Then open "GTP_Intersection_Numbers.nb" and execute the "Load the package" section. Then proceed to the next section where you are asked to draw a GTP in a pop-up window.
